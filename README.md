## Tech Stack Overview

- **Languages:** Python 3.9+, JavaScript (ES6+), HTML5, CSS3, SQL
- **AI / ML / DS:** PyTorch, Ultralytics YOLO, Scikit-Learn, XGBoost, NLTK, Pandas, NumPy, Matplotlib, Seaborn
- **GenAI & LLMs:** Groq API (Llama 3.3 70B), RAG pipelines, Chain-of-Thought prompting, Guardrails
- **Backend & Full-Stack:** Flask, Django, Node.js, Express.js, SQLite, SQLAlchemy, JWT, Bcrypt, WebSockets, WebRTC
- **Frontend & Desktop UI:** React, Vite, Chart.js, Leaflet, Streamlit, CustomTkinter, Tkinter

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/amnamine/Internships_CodeAlpha_DecodeLabs_Progree.git
   cd Internships_CodeAlpha_DecodeLabs_Progree
   ```
2. **Navigate to any track and task folder** (e.g., `cd DecodeLabs/Backend/"Task 2"` or `cd Progree/Python/"Task 4"`).
3. **Follow the local `README.md`** inside each track for specific `pip install -r requirements.txt` or `npm install` instructions.
