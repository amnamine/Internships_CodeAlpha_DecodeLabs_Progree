REST Core Concepts

Understand how stateless web servers communicate using HTTP.

GET vs POST

HTTP defines standard methods to express intent on server resources.

  • GET Retrieve data: Safe, idempotent, and cacheable. Requests should never modify server state.
  • POST Submit data: Non-idempotent. Creates or processes a new resource using JSON in the request body.

Routing Logic

Routes map HTTP methods and URI paths to specific controller actions on the server.

GET /api/items Fetch list of items
GET /api/items/:id Fetch item details
POST /api/items Create new item

Stateless constraint

Every request from client to server must contain all the information necessary to understand and process the request.

The server does not store active session tokens or states; it simply processes input and responds.
