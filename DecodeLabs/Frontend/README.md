## ℹ️ Overview

This repository contains all four task implementations along with their respective project specification PDF documents for the **DecodeLabs Frontend Engineering Program**. Each task demonstrates key milestones in modern web development:

1. **HTML5 Semantic Structuring & Modern CSS3 Aesthetics**
2. **Advanced Layout Engines (Flexbox/Grid), Responsive Breakpoints & Dynamic Color Themes**
3. **Vanilla JavaScript DOM Manipulation, Reactive State Management & Interactive UI Components**
4. **Comprehensive Form Architecture, Real-Time Validation, Password Entropy Analysis & Multi-Step Wizards**

## 💻 Projects Breakdown

### [Task 1: Static Webpage Design](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%201)
- **Folder**: [`Task 1`](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%201)
- **Description**: A modern, high-aesthetic static showcase page implementing modern typography (`Plus Jakarta Sans`), glassmorphism card designs, animated canvas background, and smooth navigation.
- **Highlights**:
  - Semantic HTML5 layout (`<nav>`, `<header>`, `<main>`, `<section>`, `<footer>`).
  - Dark/Light mode toggle with smooth CSS variable transitions.
  - Interactive hero section with floating animated ambient blobs.
  - Hover micro-interactions, responsive flex layout, and feature cards.

### [Task 2: Responsive Web Experience](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%202)
- **Folder**: [`Task 2`](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%202)
- **Description**: An ultra-responsive web application featuring multi-theme engine switching, command palette system, audio sound effects, interactive HTML5 particle canvas, and responsive component grids.
- **Highlights**:
  - Dynamic Theme Engine (Cyberpunk, Midnight, Emerald, Sunset, Light).
  - Keyboard Command Palette (`Ctrl + K` or `Cmd + K`) for rapid navigation.
  - Web Audio API Sound Effects (subtle audio feedback on click/interactions).
  - Responsive Grid & Media Explorer with view toggling (Grid vs List).

### [Task 3: Interactive Web Elements Showcase](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%203)
- **Folder**: [`Task 3`](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%203)
- **Description**: A JavaScript DOM showcase and interactive web dashboard featuring real-time state management, interactive quiz module, UI component sandbox, dynamic task manager, and filterable content catalog.
- **Highlights**:
  - Live UI Sandbox: Modify component styles, borders, shadows, and content in real-time.
  - Interactive Quiz Module: Instant feedback, score tracking, progress bar, and result recap.
  - Dynamic Task Hub: CRUD operations on task cards with status tracking.
  - Custom DOM particle canvas engine and responsive navbar.

### [Task 4: OmniForm Studio — Form Design & Validation Suite](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%204)
- **Folder**: [`Task 4`](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%204)
- **Description**: A flagship client-side form processing platform featuring real-time input validation, interactive multi-step onboarding wizard, password entropy strength analyzer, live JSON payload telemetry, and custom form controls.
- **Highlights**:
  - Real-Time Validation: Regex check for email, telephone, username, and custom fields.
  - Password Entropy & Strength Meter: Visual gauge checking length, uppercase, lowercase, numbers, and special characters.
  - Dual Mode Support: Switch seamlessly between Multi-Step Wizard mode and Single Page Form view.
  - Live Data Inspector: Interactive JSON telemetry pane displaying form state as the user types.

## 🛠️ Tech Stack & Architecture

- **Core Technologies**: Vanilla HTML5, CSS3, JavaScript (ES6+).
- **Styling Architecture**: Custom CSS Variables (Design Tokens), Flexbox, CSS Grid, Glassmorphism, CSS Keyframe Animations.
- **Typography & Icons**: Google Fonts (`Outfit`, `Plus Jakarta Sans`, `JetBrains Mono`), FontAwesome 6 Icons.
- **Browser APIs**: Web Storage API (`localStorage`), Web Audio API, Canvas API, DOM Mutation & Event Listeners.

## ⚙️ Getting Started

No build tools or external CLI packages are required to run these projects. They are built using standard web technologies and run directly in any browser.

1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd Frontend
   ```

2. **Open any task directly in your browser**:
   - Open [`Task 1/index.html`](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%201/index.html)
   - Open [`Task 2/index.html`](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%202/index.html)
   - Open [`Task 3/index.html`](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%203/index.html)
   - Open [`Task 4/index.html`](file:///d:/AMINE2/COURS%20FAC/travaux/DECODELABSINTERNSHIP/WEB/Frontend/Task%204/index.html)

3. **Or launch using Live Server**:
   If using VS Code, right-click on any `index.html` file and select **Open with Live Server**.
